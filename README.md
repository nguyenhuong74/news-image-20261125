A program that draws a one-page newspaper front page summing up the world news of Tuesday 25 November 2026 as a 1024x1024 PNG. It uses only the Python 3.13 standard library: a hand-written 5x7 bitmap font and a from-scratch PNG encoder, no network, no files read at run time. The page carries six verified stories of the day — tankers hit by mines in the Strait of Hormuz, Ukraine's strikes on Russian warplanes and refineries, the killing of Hamas's northern Gaza security chief, Shenzhou-24 carrying the first Pakistani into orbit, the Solomon Islands–Australia security treaty, and RSF drone strikes in Sudan — plus four short briefs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
